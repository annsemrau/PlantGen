# Foliage 3D mesh reconstruction & generation pipeline

This project aims to create an entire procedure for reconstructing visually correct representations of trees and other types of foliage from input images. It was a core part of my master thesis.
This project was made in Unreal Engine 5.4, using Procedural Content Generation framework to generate foliage on trees. 

## Phenomenological growth model 
Parametric growth creates a realistic, botanically correct objects.
This stage takes a set of rules to reconstruct a model of a given species, classified from an image. Skeleton is constructed within boundaries determined from the input image.
The skeleton is represented in a form of list of vertices and edges in 3D space, which will be a base for mesh construction in the next stage of the pipeline.

## Custom SDF-based resource distribution
Phenomenological models use resources (such as light) as a determinant for the growth of branches. I proposed a method where it is estimated that each node is equally covered by a sphere of leaves (a standard assumption for resource allocation in botanical simulations) and I was tracing the amount of light rays intersecting other nodes, thus succesfully blocking the amount that reaches the evaluated node.

## synthesizing dataset
For the machine learning purposes I decided to synthesize my own dataset from models previously generated by my framework. I used UnrealCV plugin for Unreal to automate captures. I added camera position, angle and weather randomization, as well as different parameters of generated trees.

## Mask extraction
I designed an algorithm to extract and transform a tree's silhouette into an SDF volume. I was inspired by the RBV tree reconstruction method. The SDF shape description can be used with pathtracing to determine the end of generation for each step of the phenomenological growth.
